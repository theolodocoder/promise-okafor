JobWhisper is an AI career product: a live interview copilot, a meeting notetaker, auto-apply and a resume builder, on web, desktop and mobile. I was the first frontend engineer and led the frontend from the first commit until the company closed in November 2026.

I set up one codebase for every app, with a shared design system and an API client generated from the backend contract. Then I built and ran the hard parts: the live path, the desktop app and the mobile app. Each one has its own story below.
